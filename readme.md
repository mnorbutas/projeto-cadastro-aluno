## Sobre o Projeto
Esse **Sistema de Cadastro de Alunos** é uma aplicação FullStack desenvolvida como um projeto de revisão de conteúdo no curso de Desenvolvimento de Sistemas, oferecido pelo SENAI Sorocaba - Gaspar Ricardo Junior, ministrado pelo Prof. [Vedilson Prado](https://github.com/vedilsonprado). O objetivo do projeto é consolidar conhecimentos em criação de API RestFull, manipulação de Banco de Dados Relacional e integração com o Frontend usando JavaScript.

A aplicação permite o gerenciamento completo (CRUD) de alunos, incluindo validações de regras de negócio e persistência de dados.

## Tecnologias Utilizadas

### Backend
- **Java 17:** Principal lingua
    - **Spring Boot:** Framework para a criação da API.

### Banco de Dados
-**MySQL:** Banco de Dados Relacional.

### Frontend
-**HTML5 % CSS3:** Estrutura semântica e estilização.
-**JavaScript:**Lógica do cliente e consumo de API.

## Como executar o projeto

### 1. Banco de Dados
- Crie o banco de dados MySQL executando o script SQL:
```sql
CREATE DATABASE db_cadastro_aluno;
```

### 2. Backend
- Clonar repositório.
- Configure o arquivo application.propriets com suas credenciais
- A API rodará em: `http://localhost:8080`

### 3. Frontend
- Navegue até a pasta do Frontend.
- Acesse o index.html no navegador.
